### B. Chi tiết từng trang

#### 1. TRANG CHỦ (Homepage)

**Layout lấy cảm hứng từ TopGear:**

- **Hero Section**: 1 bài viết nổi bật, ảnh full-width, tiêu đề overlay lớn
- **Breaking News Bar**: thanh tin nóng chạy ngang (nếu có tin quan trọng)
- **Grid bài viết**: 2-3 cột, xen kẽ bài lớn/nhỏ theo mẫu magazine
- **Chuyên mục nổi bật**: Xe điện, Giá xe tháng này, Video mới nhất
- **Sidebar**: Xe xem nhiều nhất, Xe sắp ra mắt tại VN
- **Newsletter CTA**: Form đăng ký nhận tin hàng tuần

#### 2. TRANG ĐÁNH GIÁ XE (Review Page)

**Kết hợp cả TopGear + MotorTrend:**

- **Ảnh gallery lớn** trên cùng (10-30 ảnh chất lượng cao)
- **Score card nổi bật**: Điểm tổng /10 + điểm thành phần (Thiết kế, Vận hành, Tiện nghi, Giá trị)
- **Quick Specs Box**: Thông số nhanh (giá, mã lực, 0-100km/h, tiêu hao nhiên liệu)
- **Verdict Box**: Kết luận ngắn gọn ở đầu bài (cho người lười đọc)
- **Nội dung chi tiết**: Ngoại thất → Nội thất → Vận hành → An toàn → Kết luận
- **Pros & Cons**: Bảng ưu/nhược điểm
- **Xe cạnh tranh**: Link đến các đối thủ cùng phân khúc
- **Bảng thông số đầy đủ**: Bảng chi tiết có thể mở rộng/thu gọn
- **Bình luận**: Hệ thống comment

#### 3. TRANG TÌM XE / CƠ SỞ DỮ LIỆU XE (Car Finder)

**Lấy từ MotorTrend, bản địa hóa cho VN:**

- **Bộ lọc thông minh**: Giá (VNĐ), Hãng, Phân khúc, Nhiên liệu, Số chỗ, Hộp số
- **Card xe**: Ảnh + Tên + Giá từ + Điểm đánh giá + Badge (Mới, Hot, Giảm giá)
- **Sắp xếp**: Theo giá, theo điểm, theo độ phổ biến, mới nhất
- **So sánh nhanh**: Tick chọn 2-3 xe → So sánh

#### 4. TRANG SO SÁNH XE (Compare Tool)

- Chọn 2-3 xe từ database
- Bảng so sánh song song: thông số, giá, điểm đánh giá
- Highlight khác biệt (xanh = tốt hơn, đỏ = kém hơn)
- Kết luận "Nên chọn xe nào?" từ biên tập viên
- Share kết quả so sánh qua link

#### 5. CÔNG CỤ ĐỊNH GIÁ XE CŨ

- Nhập: Hãng, dòng, đời, phiên bản, số km, tình trạng
- Kết quả: Giá ước tính (khoảng giá min-max)
- Dựa trên dữ liệu thị trường VN

## IV. HỆ THỐNG ĐA NGÔN NGỮ (i18n)

### Chiến lược URL

```
Tiếng Việt (mặc định):
  xeoto.vn/tin-tuc/vinfast-vf9-2026
  xeoto.vn/danh-gia/toyota-camry-2026
  xeoto.vn/tim-xe?hang=toyota&gia=500-800

English:
  xeoto.vn/en/news/vinfast-vf9-2026
  xeoto.vn/en/reviews/toyota-camry-2026
  xeoto.vn/en/cars?brand=toyota&price=500-800
```

### Cách triển khai

- **next-intl** hoặc **next-i18next** cho Next.js
- Nội dung bài viết: Viết tiếng Việt trước → dịch/viết lại English sau (không dịch máy)
- UI labels: File JSON cho mỗi ngôn ngữ
- URL slug: Mỗi ngôn ngữ có slug riêng
- SEO: Thẻ `hreflang` cho mỗi trang, sitemap riêng theo ngôn ngữ
- Tự động detect ngôn ngữ theo location nhưng cho phép user chuyển đổi

## V. CÔNG NGHỆ ĐỀ XUẤT (Tech Stack)

### Frontend

| Thành phần | Công nghệ | Lý do |
|------------|-----------|-------|
| Framework | **Next.js 15 (App Router)** | SSR/SSG tốt cho SEO, React ecosystem lớn, i18n tốt |
| Styling | **Tailwind CSS** | Nhanh, responsive, dễ maintain |
| UI Components | **Radix UI + custom design system** | Accessible, không bị "generic" |
| Animation | **Framer Motion** | Hiệu ứng mượt, magazine-feel |
| Image handling | **next/image + Cloudinary** | Tối ưu ảnh tự động, lazy load, responsive |
| Video player | **Video.js hoặc Plyr** | Custom player, nhúng YouTube |

### Backend & CMS

| Thành phần | Công nghệ | Lý do |
|------------|-----------|-------|
| CMS | **Strapi v5 (Headless CMS)** | Open-source, REST + GraphQL, i18n built-in, custom content types |
| Database | **PostgreSQL** | Mạnh mẽ, phù hợp dữ liệu xe phức tạp |
| Search | **Meilisearch hoặc Elasticsearch** | Full-text search nhanh, hỗ trợ tiếng Việt |
| Cache | **Redis** | Cache bảng giá, thông số xe, kết quả tìm kiếm |
| File Storage | **AWS S3 + CloudFront CDN** | Lưu trữ ảnh/video, phân phối nhanh toàn cầu |

### Infrastructure

| Thành phần | Công nghệ | Lý do |
|------------|-----------|-------|
| Frontend hosting | **Vercel** | Deploy Next.js nhanh, CDN global, preview deployments |
| Backend hosting | **AWS EC2 hoặc DigitalOcean** | Chạy Strapi + PostgreSQL |
| CDN | **CloudFront hoặc Cloudflare** | Tối ưu tốc độ tải tại VN và quốc tế |
| Monitoring | **Sentry + Google Analytics 4** | Theo dõi lỗi + traffic |
| CI/CD | **GitHub Actions** | Auto deploy khi push code |

## VI. CƠ SỞ DỮ LIỆU XE (Car Database Schema)

### Cấu trúc dữ liệu

```
Brand (Hãng xe)
  ├── id, name_vi, name_en, logo, country, description
  │
  └── Model (Dòng xe)
        ├── id, brand_id, name, slug, segment, body_type
        ├── price_from, price_to (VNĐ)
        ├── status (đang bán / ngừng bán / sắp ra mắt)
        │
        └── Variant (Phiên bản)
              ├── id, model_id, name, year, price
              │
              ├── Engine (Động cơ)
              │   ├── type (xăng/diesel/điện/hybrid)
              │   ├── displacement, horsepower, torque
              │   ├── fuel_consumption, 0_to_100
              │   └── transmission, drivetrain
              │
              ├── Dimensions (Kích thước)
              │   ├── length, width, height, wheelbase
              │   ├── ground_clearance, trunk_volume
              │   └── curb_weight, seating_capacity
              │
              ├── Features (Trang bị)
              │   ├── safety_features[]
              │   ├── comfort_features[]
              │   ├── tech_features[]
              │   └── exterior_features[]
              │
              └── Media
                  ├── images[], videos[]
                  └── 360_view_url
```

### Dữ liệu cần thu thập ban đầu

- **Tất cả xe đang bán chính hãng tại VN** (~40 hãng, ~300 dòng, ~1500 phiên bản)
- Giá niêm yết + giá lăn bánh ước tính theo tỉnh/thành
- Ảnh chính hãng (press photos) + ảnh tự chụp
- Thông số kỹ thuật đầy đủ
