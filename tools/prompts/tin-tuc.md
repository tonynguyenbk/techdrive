# Prompt Template — Tin tức ô tô

## Cách dùng
1. Copy toàn bộ prompt bên dưới
2. Thay thế các phần trong [ngoặc vuông]
3. Paste vào Claude hoặc ChatGPT
4. Copy output → Google Docs → publish lên Strapi

Viết bài tin tức hoàn chỉnh theo cấu trúc sau:

**TITLE_VI:** [Tiêu đề tiếng Việt, 60-70 ký tự, có từ khoá chính, hấp dẫn]

**META_DESCRIPTION:** [SEO description 150-160 ký tự, có call-to-action]

[Nội dung bài viết đầy đủ theo cấu trúc:]
